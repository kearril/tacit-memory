# TacitMemory 界面设计规范

本文档规定 Web 界面长什么样、怎么动。页面有哪些功能见 `docs/design.md` 的「Web 界面」一章。编写或修改界面代码前先读本文。

## 1. 原则

- **清晰先于装饰**：这是一个看状态、改配置的工具，任何视觉处理都不能妨碍阅读数字、日志与表单。
- **有自己的样子**：组件库只提供结构与交互，不沿用它的默认外观；配色、字体、间距、圆角全部来自本文的令牌。
- **动效是界面的一部分**：状态变化用动效交代来龙去脉，而不是突然切换。
- **只引用令牌**：页面与组件不写具体的色值、字号、间距、圆角、时长与缓动，一律引用令牌。需要的令牌不存在时，先在令牌文件中增加并在本文登记，再使用。

## 2. 设计令牌

- 令牌的数值只在 `web/src/styles/tokens.css`，浅色与深色成对写在各令牌中，随系统配色切换并支持强制颜色模式与高对比度偏好（如滚动条滑块自动加深、强制颜色模式下补回系统焦点轮廓），每个令牌的用途写在它旁边的注释里。本文不抄数值，也不逐个登记令牌。
- 需要的令牌不存在时，先在令牌文件中增加并写明用途，再使用；改动已有数值时，先在仪表盘上核对两套配色。

Tailwind 的主题只暴露令牌，类名里写的是令牌名（如 `bg-surface`、`text-ink-muted`、`h-control`），不写数值。唯一的例外是零：间距阶梯被整体去掉后，`inset-0`、`top-0` 这类类名需要主题里显式命名的 0。悬停浮起与按下缩放合为一个工具类 `lift`，可交互的卡片与按钮都用它。

### 状态的表达

- 状态色的含义固定：成功表示正常与完成，警告表示降级或需要留意（如辅助模型冷却中、待处理问题），错误表示失败或被拒绝，信息表示中性的提示。
- 不单靠颜色区分状态：同时给出图标或文字。
- 辅助模型的三种状态（可用、不可用、未配置）外观必须能区分，「未配置」不是错误，不用错误色。

## 3. 排版与布局

### 视觉方向

柔和的便当盒：雾色的页面底色上铺白色（深色下为略亮于底色的）卡片，卡片大圆角、带淡淡的有色阴影，强调色为靛蓝。卡片不加边框，靠表面色与阴影从底色上分出来；卡片内部的分区用细分隔线。卡片是一个按高度区分主次的家族（见下文卡片），一个视野里最多两张浮起卡，其余降为平铺、染色或描边，避免满屏一样的白卡。

### 布局

- **外壳**：宽屏下是左侧固定的侧边栏（宽度为侧边栏令牌，内容为品牌、五项导航与当前连接的身份），主区占其右侧的剩余空间。窄屏下侧边栏隐藏，页首吸顶，左侧的菜单按钮打开同样内容的抽屉。外壳最前放默认视觉隐藏、键盘聚焦时显示的「跳至主内容」链接，方便键盘用户直接越过侧栏进入主区。
- **主区**：最大宽度为页面令牌，在剩余空间中水平居中；四周留页面边距（窄屏较小，宽屏为大间距）。
- **设置页**：不用卡片网格，是从上往下读的一列，宽度为设置列令牌，在主区中居中。每节是一张描边卡，浅强调色底块上的图标与标题压在上边框上，用途说明是卡内第一行；页面上只有这一层盒子。节内是设置组：组不加框也不加线，只有小标题与说明，组与组之间为区块间距；一行一项，项之间为常规间距；名称在左（宽度为设置项名称令牌），控件在右，窄屏叠成上下。各节的清单放在侧边栏「设置」之下。
- **提示词页**：比设置页宽的一列，一次只放一份文档的卡片，卡头与设置页相同，另有徽标与信息按钮，说明文字收在信息按钮打开的浮层里，不占卡片正文；文档的文本在带行号与语法高亮的 Markdown 编辑器里。四份文档的清单放在侧边栏「提示词」之下，样式与设置页的节清单相同。
- **记忆页**：五个视图的清单放在侧边栏「记忆」之下。各视图顶部是吸顶条（作用域、主线、筛选或检索条件），浮起后折叠成一行；检索视图用页面宽度，结果与检索单元的去向左右并排。
- **仪表盘**：最宽的断点下是 12 列的便当盒网格，概览（染色卡）与记忆活动各占一整行，其下四张小卡片（平铺卡）一行、上方有分组眉标「状态」，最后是左侧 4 列上下叠放的服务与同步、右侧 8 列的客户端；卡片之间为区块间距。更窄时所有卡片单列，按标记的顺序排列，把要处理的放在前面（顺序见 `docs/design.md`）。
- **同一行的卡片等高**：仪表盘卡片的命令在卡头，正文从上往下排，同一行里内容少的卡片在底部留白，而不是在正文中间空出一段；卡片底部不放操作栏。

### 响应式

- 页面在手机宽度下可用：导航收起，卡片与表单单列排列，表格可横向滚动或改为列表。
- 日志、路径、键名、短码用等宽字体，过长时可横向滚动，不截断内容。

### 字号与间距

- 仪表盘不另设页面标题，卡片标题即最高一级的标题。状态卡片中最重要的一个数字或时间（如上次整理在几天前、最新备份的时间）用小节标题字号、半粗，其下一行用辅助标注字号写补充。
- 正文与清单用说明文字字号；辅助标注字号只用于数字旁的单位、补充说明与徽标，不用于需要阅读的整句。
- 卡片内边距为区块间距，卡片内各部分之间为常规间距；标签与值成对的清单（如服务卡片中的地址）用两列布局，标签为次要文字。

## 4. 组件约定

- 组件的结构与交互取自 shadcn/ui，外观按本文的令牌重写；不直接使用未经改写的默认样式。
- 文案中英两套，组件内不写死任何面向人的文字。
- 危险操作（恢复、解除绑定、重建索引）先经确认对话框；确认按钮写明动作本身，不写「确定」。
- 长时间的操作显示进行中的状态，期间禁用触发它的按钮；结束后给出结果或错误，错误显示服务返回的说明原文。
- 表单的校验错误显示在对应字段旁，文字取自服务返回的说明。
- 操作结果与提示按下表选择控件，同一种情况在各页面用同一种控件：

| 控件 | 用在哪 | 例子 |
| :--- | :--- | :--- |
| 字段旁的错误 | 某个输入不合法 | 访问密码太短 |
| 提示条（Alert） | 被拒绝或失败，或需要读懂原因、采取行动的提示；留在出事的位置旁边，不自动消失 | 不能清除访问密码、备份失败 |
| 轻提示（Toast） | 命令成功、无需后续操作；在右下角出现，几秒后自动消失 | 访问密码已保存、备份完成 |
| 确认对话框 | 危险操作执行前的确认 | 清除访问密码、重建索引 |
| 模态对话框 | 有自己的内容与步骤的任务 | 恢复备份 |

  失败不只用轻提示表达，轻提示只承载成功。界面没有通知中心：没有需要推送给用户的后台事件，需要处理的事项由仪表盘的待处理列出。
- 密码与密钥只用一个输入控件 `PasswordInput`，它的显示切换只作用于框里已有的文字，不另取数据；同一页有多个时，切换按钮的名称带上字段名。
- 一行胶囊、页签或小卡片放不下时换行，不做横向滚动条；横向滚动只留给内容本身（代码块、表格、热力图）。
- 一个部件的外观定稿后就抽成共用部件（通用的在 `web/src/components/ui/`，只用于某一页的放在该页目录的 `parts.tsx`），各页面都用它；做新视图时先找已有的部件，不在页面里另写一份相似的。已有部件不合用时改部件本身（加参数或变体），不在页面里复制后改样式。

### 卡片家族

  - 浮起卡（默认）：表面色加静止阴影，放这一页要读、要操作的内容，一个视野里最多两张。可交互的浮起卡悬停时上浮并换成悬停阴影，按下时缩小；只展示信息的卡片不动。
  - 染色卡：浅强调色底、无阴影，放摘要与结论（仪表盘概览、主线概况、单页页头），每页最多一张、放在最上面，不放操作控件；卡内原本的浅强调色块改用表面色。
  - 平铺卡：表面色、无阴影，放配角与辅助信息（仪表盘的状态卡与客户端、最近活动、主线约定、相关页面、检索单元的去向），卡头图标用次要文字色；内容需要处理时升为浮起卡，如画像候选有待审条目时。
  - 描边卡：无底色，一道加强的细边框，标题与图标压在上边框上，用于很多结构相同的小节并列，只用在设置页。
  - 页签卡：标题从卡片左上角伸出成页签，页签与卡身之间是内凹圆角，二者共用一道阴影；用于一页里并列的几个大分区（画像的四个小节）。页签只写图标、名称与条数，操作放在卡身第一行右侧。
  - 分组眉标：几张同级的卡片合成一组时，组名以小号半粗的次要文字写在卡片外的上方，每张卡片仍有自己的标题。

## 5. 动效

- 动效服务于理解：说明东西从哪来、到哪去、状态变成了什么。不为动而动，不阻挡操作，不让用户等动画结束。
- **减少动态效果**：系统开启该设置时，界面动效退化为即时切换或简单的淡入淡出。

已有的动效：

- 悬停、焦点与颜色变化用快速时长与默认缓动，是组件的默认过渡。
- 可交互的卡片与按钮共用 `lift`：悬停上浮、按下缩小；减少动态效果时只变颜色与阴影，不移动。
- 进行中的命令把按钮图标换成转圈；减少动态效果时转圈不转。
- 热力图在悬停或聚焦一格时，下方一行就地换成那一天的内容，行高固定，卡片不跳动。

页面切换、卡片与列表项的出现、数值变化、对话框与浮层的出现与消失尚未加入动效，目前为即时切换；要加时先用样张与用户确定。
