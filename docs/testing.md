# TacitMemory 测试规范

本文档定义测试接缝、测试环境与运行方式。

## 1. 两个测试接缝

测试只针对公开契约编写，不直接测试 `internal` 实现（唯一例外见第 3 节）。

1. **`tests/TacitMemory.Core.Tests`：门面接缝**
   - 通过 `TacitMemory.Core` 的公开门面测试；
   - 每个测试使用独立的临时用户主目录、临时 `TACIT_HOME` 与临时记忆仓库（`TestHome`），真实文件、真实 `git`；绑定只写入临时用户主目录，从不碰真实的客户端配置；
   - 已覆盖：初始化（生成的文件与首个提交、非空目录被拒、重复执行只补骨架、与已有配置冲突、语言推断）；配置的默认值与各类校验错误、未初始化、`rules.md` 重新生成与超限；常驻区块的渲染、标记校验、区块外字节不变、非 UTF-8 文件不改动；绑定与解绑（`mcp.json` 的保留与拒绝、逐字节恢复、新建文件的删除）；服务端说明的内容与长度上限；运行中修改画像与项目目录后的更新；新建细节页（页面标识与上限校验、页头写法、只提交本次文件、已存在时拒绝、串行写入）与按页面标识读取（短码、页头损坏时照常读取）；按小节新增、按短码替换与删除（缺失或过期的短码被拒）、页头改标题与追加别名、`related` 替换、每次写入更新 `dates`、无变化不提交、手动修改过的文件连同修改一起提交、页头损坏时拒绝写入；全文检索（中文两字切分、单字子串匹配、带标点的写法、项目与日期筛选、同页合并、页面级命中、`topK`、无结果）与索引同步（写入后立即可查、运行中手动编辑、启动时增量同步、索引损坏时重建、跳过非 UTF-8 页面），使用真实 SQLite 索引与真实 `vec0`；向量检索（换种说法也能命中、两路都命中者排前、嵌入模型不可用时退回全文并在恢复后补齐、嵌入模型名或向量长度变化后重做）；重复页判断（三档分流、配置的阈值优先、只取同项目的页、问题为英文且内容保持原文、决策模型不可用或缺密钥时放行并注明）；每日自动备份（首次写入后生成、同日不重复、保留份数、`keep: 0` 关闭、zip 不含 `.cache`、清单内容、明文密钥提示、备份失败不影响写入）；
   - 已覆盖（精排）：按 `/v1/rerank` 返回的分数排序，低于 `minRerankScore`（默认 0.001）的单元丢弃，全部丢弃时返回"没有相关记忆"；同页按最高分呈现，`topK` 按页截取；替身不可用时保留融合顺序并注明，冷却后恢复过滤。
   - 计划覆盖：写入校验与上限、凭据拦截、候选计天与拒绝列表、近期主线返回与同主题退回、格式问题与体检报告。
2. **`tests/TacitMemory.Mcp.Tests`：MCP 接缝**
   - 复用 `TestHome`，在进程内以真实 HTTP 启动 `McpHost`，用 SDK 的 MCP 客户端调用；
   - 已覆盖：服务端说明随连接下发、工具列表与标注、prompt 列表为空、经工具新建并读回一页、经工具按短码替换小节并读回、`add_aliases` 经工具写入页头、缺参数时的错误标记、端口被占用时不启动；
   - 计划覆盖：工具参数与按 `op` 的校验、返回格式与错误标记、工具标注、prompt 列表与现场生成的内容。

## 2. 模型依赖

测试不调用真实模型，也不访问网络。`ModelDouble` 是进程内的 HTTP 替身，按用例返回确定的结果：`/v1/embeddings` 默认返回文本相邻字对的散列向量（措辞相近即相近），也可按用例指定任意文本的向量；`/v1/systemone` 按用例给出选择题各选项与真伪题的概率，并记录最近一次请求；`/v1/rerank` 默认给每个文本 1.0 分，可按用例指定分数。每个模型都可设为不可用（立即返回 503）。`TestHome.InitReady` 默认让所有模型指向一个始终不可用的共享替身，不涉及模型的测试因此不会等待网络；用到模型的测试传入自己的替身。模型失败后的冷却期用 `TestHome.Clock` 向前拨动跨过。

## 3. 本地化完整性

两种写法齐全由编译期保证（见 `docs/architecture.md` 第 3 节）。`TacitMemory.Core.Tests` 中的本地化测试检查编译器看不到的部分：每项两种写法都非空、格式占位符一致；结构词在两种语言之间互不重复；`init` 写出的每个标题都是该语言的结构词。这是唯一直接读取 `internal` 类型的测试：文本表本身就是被检查的对象，没有公开契约可以替代。

## 4. 提示词场景评测

常驻区块外壳与记忆规则的措辞不由自动测试保证。模型行为无法完全预测，措辞主要依据实际使用体验调整；某个场景需要确认时，在真实客户端中按下列场景直接评测：

| 场景 | 观察 |
| :--- | :--- |
| 无关任务 | 是否把画像条目硬套进来 |
| 涉及协作规则的任务 | 是否不加声明地照做 |
| 用户当下说法与画像冲突 | 是否听用户的并提出更新记忆 |
| 触及红线的请求 | 是否守住 |
| 长对话后半段 | 画像是否仍起作用 |
| 提起记忆中有的事 | 是否先检索再回答 |
| 提起记忆中没有的事 | 是否直说不记得、不编造 |
| 随口提到近况 | 是否自然联系、不复述 |
| 新会话直接写代码 | 是否不主动提起旧事 |

判断阈值的默认值同样以真实中文样本在真实决策模型上测定。

## 5. 运行方式

默认只运行与当前变更直接相关的测试，不自动运行全量测试。测试使用真实 `git`，需要它在 `PATH` 中。

```powershell
dotnet test tests/TacitMemory.Core.Tests                               # 门面接缝
dotnet test tests/TacitMemory.Mcp.Tests                                # MCP 接缝
dotnet test tests/TacitMemory.Core.Tests --filter "FullyQualifiedName~InitTests"   # 单个测试类
dotnet test TacitMemory.slnx                                           # 全量
```
