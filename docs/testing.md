# TacitMemory 测试规范

本文档定义测试接缝、测试环境与运行方式。

## 1. 两个测试接缝

测试只针对公开契约编写，不直接测试 `internal` 实现。

1. **`tests/TacitMemory.Core.Tests`：门面接缝**
   - 通过 `TacitMemory.Core` 的公开门面测试；
   - 每个测试使用独立的临时记忆仓库（真实文件、真实 `git`、真实 SQLite 索引）；
   - 覆盖：写入校验与上限、更新还是新建、候选去重与门槛、近期摘要折叠约束、常驻区块渲染与标记校验、检索的筛选与排序、手动编辑后的索引同步、索引版本不符时的重建。
2. **`tests/TacitMemory.Mcp.Tests`：MCP 接缝**
   - 在进程内启动 HTTP 宿主，用真实 MCP 客户端通过 HTTP 调用工具与 prompt；
   - 覆盖：工具参数与返回格式、错误返回、prompt 列表与内容。

## 2. 模型依赖

嵌入模型与 reranker 是必需配置。测试中以本地测试替身服务实现 `/v1/embeddings` 与 `/v1/rerank`，返回确定性的结果，测试不依赖真实模型或网络。

## 3. 运行方式

默认只运行与当前变更直接相关的测试，不自动运行全量测试。具体命令待测试工程建立后补充。
