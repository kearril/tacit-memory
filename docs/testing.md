# TacitMemory 测试规范

本文档定义测试接缝、测试环境与运行方式。

## 1. 两个测试接缝

测试只针对公开契约编写，不直接测试 `internal` 实现（唯一例外见第 3 节）。

1. **`tests/TacitMemory.Core.Tests`：门面接缝**

   - 每个测试使用独立的临时用户主目录、临时 `TACIT_HOME` 与临时记忆仓库（`TestHome`），真实文件、真实 `git`；绑定只写入临时用户主目录，从不碰真实的客户端配置；

## 2. 模型依赖

测试不调用真实模型，也不访问网络。`ModelDouble` 是进程内的 HTTP 替身，按用例返回确定的结果：`/v1/embeddings` 默认返回文本相邻字对的散列向量（措辞相近即相近），也可按用例指定任意文本的向量；`/v1/systemone` 按用例给出选择题各选项的概率（默认选"都不是"），并记录请求次数与最近一次请求；`/v1/rerank` 默认给每个文本 1.0 分，可按用例指定分数。每个模型都可设为不可用（立即返回 503）。`TestHome.InitReady` 默认让所有模型指向一个共享替身：嵌入模型与 reranker 不可用，决策模型对一切选择题答"都不是"，因此不涉及模型的测试不会等待网络，写入也不会被判为重复页；用到模型的测试传入自己的替身。测试中形似凭据的样本在运行时拼接，源码里不出现完整的凭据格式。模型失败后的冷却期用 `TestHome.Clock` 向前拨动跨过。

## 3. 本地化完整性

两种写法齐全由编译期保证（见 `docs/architecture.md` 第 3 节）。`TacitMemory.Core.Tests` 中的本地化测试检查编译器看不到的部分：每项两种写法都非空、格式占位符一致；结构词在两种语言之间互不重复；`init` 写出的每个标题都是该语言的结构词。这是唯一直接读取 `internal` 类型的测试：文本表本身就是被检查的对象，没有公开契约可以替代。

## 4. 提示词场景评测

常驻区块外壳与记忆规则的措辞不由自动测试保证。模型行为无法完全预测，措辞主要依据实际使用体验调整；某个场景需要确认时，在真实客户端中按下列场景直接评测：

| 场景 | 观察 |
| :--- | :--- |
| 无关任务 | 是否把画像条目硬套进来 |
| 涉及协作规则的任务 | 是否不加声明地照做 |
| 用户当下说法与画像冲突 | 是否听用户的并提出更新记忆 |
| 触及红线的请求 | 是否守住 |
| 长对话后半段 | 画像是否仍起作用 |
| 提起记忆中有的事 | 是否先检索再回答 |
| 提起记忆中没有的事 | 是否直说不记得、不编造 |
| 随口提到近况 | 是否自然联系、不复述 |
| 新会话直接写代码 | 是否不主动提起旧事 |

判断阈值的默认值同样以真实中文样本在真实决策模型上测定。

## 5. 运行方式

默认只运行与当前变更直接相关的测试，不自动运行全量测试。测试使用真实 `git`，需要它在 `PATH` 中。

```powershell
dotnet test tests/TacitMemory.Core.Tests                               # 门面接缝
dotnet test tests/TacitMemory.Mcp.Tests                                # MCP 接缝
dotnet test tests/TacitMemory.Core.Tests --filter "FullyQualifiedName~InitTests"   # 单个测试类
dotnet test TacitMemory.slnx                                           # 全量
```
