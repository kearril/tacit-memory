# TacitMemory 测试规范

本文档定义测试接缝、测试环境与运行方式。

## 1. 两个测试接缝

测试只针对公开契约编写，不直接测试 `internal` 实现。

1. **`tests/TacitMemory.Core.Tests`：门面接缝**
   - 通过 `TacitMemory.Core` 的公开门面测试；
   - 每个测试使用独立的临时记忆仓库与临时 `TACIT_HOME`（真实文件、真实 `git`、真实 SQLite 索引）；
   - 覆盖：写入校验与上限、短码引用与过期、按行修改不破坏未知内容、更新还是新建、判断三档的分流、凭据拦截、候选计天与拒绝列表、近期主线返回与同主题退回、常驻区块渲染与标记校验、服务端说明的内容与长度上限、检索的筛选与排序、手动编辑后的索引同步、格式问题与体检报告、索引版本不符时的重建、辅助模型不可用时的降级、绑定与解绑、备份与恢复。
2. **`tests/TacitMemory.Mcp.Tests`：MCP 接缝**
   - 在进程内启动 HTTP 主机，用真实 MCP 客户端通过 HTTP 调用；
   - 覆盖：工具参数与按 `op` 的校验、返回格式与错误标记、工具标注、prompt 列表与现场生成的内容、服务端说明。

## 2. 模型依赖

嵌入模型、reranker 与决策模型都是必需配置。测试中以本地测试替身服务实现 `/v1/embeddings`、`/v1/rerank` 与 `/v1/systemone`，返回确定性的结果（决策模型替身可按用例预设各选项概率）；测试不依赖真实模型或网络。

## 3. 本地化完整性

面向人的文本以中英两种写法一并定义，缺一种即无法编译。`TacitMemory.Core.Tests` 中的本地化测试检查：每项两种写法都非空、格式占位符一致；结构词在两种语言之间互不重复；`init` 写出的每个标题都是该语言的结构词。这是唯一直接读取 `internal` 类型的测试：文本表本身就是被检查的对象，没有公开契约可以替代。

## 4. 提示词场景评测

常驻区块外壳与记忆规则的措辞不由自动测试保证。模型行为无法完全预测，措辞主要依据实际使用体验调整；某个场景需要确认时，在真实客户端中按下列场景直接评测：

| 场景 | 观察 |
| :--- | :--- |
| 无关任务 | 是否把画像条目硬套进来 |
| 涉及协作规则的任务 | 是否不加声明地照做 |
| 用户当下说法与画像冲突 | 是否听用户的并提出更新记忆 |
| 触及红线的请求 | 是否守住 |
| 长对话后半段 | 画像是否仍起作用 |
| 提起记忆中有的事 | 是否先检索再回答 |
| 提起记忆中没有的事 | 是否直说不记得、不编造 |
| 随口提到近况 | 是否自然联系、不复述 |
| 新会话直接写代码 | 是否不主动提起旧事 |

判断阈值的默认值同样以真实中文样本在真实决策模型上测定。

## 5. 运行方式

默认只运行与当前变更直接相关的测试，不自动运行全量测试。测试使用真实 `git`，需要它在 `PATH` 中。

```powershell
dotnet test tests/TacitMemory.Core.Tests                               # 门面接缝
dotnet test tests/TacitMemory.Mcp.Tests                                # MCP 接缝
dotnet test tests/TacitMemory.Core.Tests --filter "FullyQualifiedName~InitTests"   # 单个测试类
dotnet test TacitMemory.slnx                                           # 全量
```
