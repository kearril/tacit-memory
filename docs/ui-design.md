# TacitMemory 界面设计规范

本文档规定 Web 界面长什么样、怎么动：设计令牌的用途、排版与组件的约定、动效与 shader 背景的规范。页面有哪些功能见 `docs/web.md`。编写或修改任何界面代码前先读本文。

各节标题后的状态标明内容是否已定：**已定**、**待定**（尚未与用户确定，到用上它的页面时用样张确定并补全本文）。

## 1. 原则（已定）

- **清晰先于装饰**：这是一个看状态、改配置的工具，任何视觉处理都不能妨碍阅读数字、日志与表单。
- **有自己的样子**：组件库只提供结构与交互，不沿用它的默认外观；配色、字体、间距、圆角全部来自本文的令牌。
- **动效是界面的一部分**：状态变化用动效交代来龙去脉，而不是突然切换。
- **只引用令牌**：页面与组件不写具体的色值、字号、间距、圆角、时长与缓动，一律引用令牌。需要的令牌不存在时，先在令牌文件中增加并在本文登记，再使用。

## 2. 设计令牌

令牌的**数值只存在于前端的令牌文件中**，本文不抄数值，只登记每个令牌的名字、用途与不该用的场合。

- 令牌文件是 `web/src/styles/tokens.css`，浅色与深色各一套；Tailwind 的主题映射在 `web/src/styles/index.css`，只暴露令牌。
- 当前的数值取自柔和界面风的定稿样张，在实现仪表盘时逐项调整，并在仪表盘完成时统一微调过一次，作为后续页面的基准。之后的页面需要新令牌时照第 1 节的原则增加，改动已有数值时先在仪表盘上核对两套配色。

### 分类（已定）

| 类别 | 管什么 |
| :--- | :--- |
| 颜色 | 背景与表面的层级、文字的层级、边框、强调色，成功、警告、错误、信息四种状态色及其浅色底，阴影的基色，热力图的五档色阶；浅色与深色两套，派生色只写一次 |
| 字体 | 界面字体、等宽字体（日志、路径、键名、代码）、字号阶梯、行高、字重 |
| 间距 | 间距阶梯，用于内边距、间隔与布局 |
| 形状 | 圆角阶梯、边框粗细、阴影层级 |
| 动效 | 时长阶梯与缓动曲线 |
| 层级 | 浮层、对话框、通知的叠放顺序 |
| 状态 | 禁用态的不透明度、悬停态的颜色比例、浅色底的颜色比例、悬停浮起与按下缩放的幅度 |

### 状态的表达（已定）

- 状态色的含义固定：成功表示正常与完成，警告表示降级或需要留意（如辅助模型冷却中、待处理问题），错误表示失败或被拒绝，信息表示中性的提示。
- 不单靠颜色区分状态：同时给出图标或文字。
- 辅助模型的三种状态（可用、不可用、未配置）外观必须能区分，「未配置」不是错误，不用错误色。

## 3. 排版与布局

### 响应式（已定）

- 页面在手机宽度下可用：导航收起，卡片与表单单列排列，表格可横向滚动或改为列表。
- 日志、路径、键名、短码用等宽字体，过长时可横向滚动，不截断内容。

### 视觉方向（已定）

柔和的便当盒：雾色的页面底色上铺白色（深色下为略亮于底色的）卡片，卡片大圆角、带淡淡的有色阴影，强调色为靛蓝。卡片不加边框，靠表面色与阴影从底色上分出来；卡片内部的分区用细分隔线。

### 布局（已定）

- **外壳**：宽屏下是左侧固定的侧边栏（宽度为侧边栏令牌，内容为品牌、五项导航与当前连接的身份），主区占其右侧的剩余空间。窄屏下侧边栏隐藏，页首吸顶，左侧的菜单按钮打开同样内容的抽屉。
- **主区**：最大宽度为页面令牌，在剩余空间中水平居中；四周留页面边距（窄屏较小，宽屏为大间距）。
- **设置页**：不用卡片网格，是从上往下读的一列，宽度为设置列令牌，在主区中居中。每节是一张卡片，卡头与仪表盘卡片相同（浅强调色底块上的图标、标题），用途说明在标题下；页面上只有这一层盒子。节内是设置组：组不加框也不加线，只有小标题与说明，组与组之间为区块间距；一行一项，项之间为常规间距；名称在左（宽度为设置项名称令牌），控件在右，窄屏叠成上下。各节的清单放在侧边栏「设置」之下。
- **提示词页**：比设置页宽的一列，一次只放一份文档的卡片，卡头与设置页相同，另有徽标与信息按钮，说明文字收在信息按钮打开的浮层里，不占卡片正文；文档的文本在带行号与语法高亮的 Markdown 编辑器里。四份文档的清单放在侧边栏「提示词」之下，样式与设置页的节清单相同。
- **记忆页**：五个视图的清单放在侧边栏「记忆」之下，样式与提示词页的文档清单相同。检索视图：检索条件一张卡片在上，查询独占一行、其余四项在宽屏下排成一行；其下宽屏为两栏（结果约占五分之二，检索单元的去向约占五分之三），窄屏叠成一列。去向的各段以细线分隔，段头是图标、名称、单元数与比例条；单元行的三列数字右对齐、用等宽数字。画像视图是阅读列：宽度与提示词页相同，顶部一排作用域胶囊吸顶（画布色底，胶囊平时是带静止阴影的表面色、选中时是强调色实底，一行放不下时横向滚动），其下四个小节与画像候选各一张卡片从上往下排，卡头是强调色图标、名称与条数，页面底部是来源文件的路径。主线视图是阅读列：顶部主线条吸顶（画布色底），在页顶时每条主线是一张侧边栏令牌宽的小卡片（表面色、静止阴影，悬停加深；选中的为浅强调色底加粗描边的强调色；未成立的为虚线描边），卡片底部一排活动条，每周一格、格间距为细描边，色阶与仪表盘热力图相同；贴住顶端后卡片收成胶囊，主线条下多一道细线。其下概况、未决事项、最近活动、主线约定、页目录各一张卡片，卡头是强调色图标与名称；概况的名称用大号字，近况是浅强调色底的圆角块；页目录是用子网格对齐列的表，表头是可点的列名，当前排序的列为强调色。活动视图是阅读列：顶部吸顶条（画布色底，贴住顶端后多一道细线）上行是月份、天数与条数、主线，下行是日期条：当月每天一格（控件高度，平分整行，窄屏不写日期数字），色阶与热力图相同；月汇总是浅强调色底的圆角块，排在时间线卡片之上；时间线卡片里各天之间留最大的间距，每天左列是大号日期与星期，右侧一条粗描边的竖轨，每条活动在轨上有一个强调色圆点（外圈一道表面色描边把竖轨断开，悬停时圆点放大），条目之间留大间距；周汇总是强调色半透明的虚线框，排在该周之后；页面底部是来源文件的路径。细节页清单同样是阅读列：顶部筛选条吸顶（画布色底），类型胶囊平时是带静止阴影的表面色、选中时是强调色实底；其下一张卡片里是用子网格对齐列的表，表头可点的列名当前为强调色，按主线排列时主线名是表中的小标题。单页的阅读列宽度相同：页头卡片，其下小节页签吸顶（胶囊同上，悬停时文字为强调色），小节在一张卡片中，各在一个虚线框里，编号是浅强调色底的圆点；相关页面是次级表面色的小块，两列排开。
- **仪表盘**：最宽的断点下是 12 列的便当盒网格，概览与记忆活动各占一整行，其下四张小卡片一行，最后是服务（4 列）与客户端（8 列）；卡片之间为区块间距。更窄时所有卡片单列，按标记的顺序排列，把要处理的放在前面（顺序见 `docs/web.md`）。
- **同一行的卡片等高**：仪表盘卡片的命令在卡头，正文从上往下排，同一行里内容少的卡片在底部留白，而不是在正文中间空出一段；卡片底部不放操作栏。
- **一排小卡片**（如待处理事项）按小卡片令牌的最小列宽自动换行。

### 字号与间距（已定）

- 仪表盘不另设页面标题，卡片标题即最高一级的标题。状态卡片中最重要的一个数字或时间（如上次整理在几天前、最新备份的时间）用小节标题字号、半粗，其下一行用辅助标注字号写补充。
- 正文与清单用说明文字字号；辅助标注字号只用于数字旁的单位、补充说明与徽标，不用于需要阅读的整句。
- 卡片内边距为区块间距，卡片内各部分之间为常规间距；标签与值成对的清单（如服务卡片中的地址）用两列布局，标签为次要文字。

## 4. 组件约定

### 已定

- 组件的结构与交互取自 shadcn/ui，外观按本文的令牌重写；不直接使用未经改写的默认样式。
- 文案中英两套，组件内不写死任何面向人的文字。
- 危险操作（恢复、解除绑定、重建索引）先经确认对话框；确认按钮写明动作本身，不写「确定」。
- 长时间的操作显示进行中的状态，期间禁用触发它的按钮；结束后给出结果或错误，错误显示服务返回的说明原文。
- 表单的校验错误显示在对应字段旁，文字取自服务返回的说明。
- 操作结果与提示按下表选择控件，同一种情况在各页面用同一种控件：

| 控件 | 用在哪 | 例子 |
| :--- | :--- | :--- |
| 字段旁的错误 | 某个输入不合法 | 访问密码太短 |
| 提示条（Alert） | 被拒绝或失败，或需要读懂原因、采取行动的提示；留在出事的位置旁边，不自动消失 | 不能清除访问密码、备份失败 |
| 轻提示（Toast） | 命令成功、无需后续操作；在右下角出现，几秒后自动消失 | 访问密码已保存、备份完成 |
| 确认对话框 | 危险操作执行前的确认 | 清除访问密码、重建索引 |
| 模态对话框 | 有自己的内容与步骤的任务 | 恢复备份 |

  失败不只用轻提示表达，轻提示只承载成功。界面没有通知中心：没有需要推送给用户的后台事件，需要处理的事项由仪表盘的待处理列出。
- 密钥字段默认隐藏，旁边有显示与隐藏的切换。
- 一个部件的外观定稿后就抽成共用部件（通用的在 `web/src/components/ui/`，只用于某一页的放在该页目录的 `parts.tsx`），各页面都用它；做新视图时先找已有的部件，不在页面里另写一份相似的。已有部件不合用时改部件本身（加参数或变体），不在页面里复制后改样式。

### 各组件的外观与变体（已定）

- **卡片**：表面色、卡片圆角、静止阴影、区块内边距。可交互的卡片悬停时上浮并换成悬停阴影，按下时缩小；只展示信息的卡片不动。
- **卡头**：标题左侧一个小图标底块（强调色的浅色底，紧凑的小图标底块令牌），状态卡片统一用这种紧凑卡头；页首的卡头用控件高度的图标底块。
- **卡头命令**（仪表盘卡片）：标题行右侧，只有图标的按钮（图标尺寸、描边），悬停或键盘聚焦时以悬停提示显示名称（关闭它打开的对话框或菜单后焦点回到按钮上，不弹出提示），读屏读出同一名称；主要命令（如立即备份）用默认按钮并带下拉箭头。跳转到别处的入口（查看日志、管理绑定）同样放在这里。
- **操作栏**（设置页的节）：卡片底部，按钮靠右；需要时左侧一行辅助标注说明按钮的作用对象（如设置页有未保存改动时说明探测要先保存）。主要动作用默认按钮，其余用描边按钮；一组同类动作（如本地与云端备份）合成一个带下拉菜单的按钮，不可用的项置灰并保留在菜单中。
- **按钮**：四种变体——默认（强调色填充）、危险（错误色填充）、描边、幽灵；常规与图标两种尺寸，高度为控件高度。悬停时上浮、按下时缩小，执行中的按钮把自己的图标换成转圈并禁用。
- **徽标**：胶囊形，浅色底配同色文字，六种色调（中性与五种状态）；前面可带一个小图标，状态不单靠颜色。
- **提示条**：浅色底配同色图标与文字，留在出事的位置；失败的提示条给出服务返回的说明原文。
- **清单中的选择**：对话框里的单选清单整行可点，选中项用强调色的浅色底，最大高度为清单令牌，超出时清单内滚动。
- **可复制的地址**：过长时截断，悬停显示全文，旁边一个复制按钮；复制成功时图标短暂变为对勾并给出轻提示。
- **分区目录**：在设置页时，侧边栏「设置」之下列出各节，左侧一条细竖线串起；正在读的一节为强调色文字与强调色竖条，有出错字段的节在名称后带危险色小胶囊写出错数。「设置」一行右侧的箭头按钮折叠或展开目录。
- **设置节标题**：小节标题字号，其下一行次要文字写用途，再下一条分隔线；立即执行、不经保存的节在标题旁带信息色徽标「立即生效」。节内的分组用小号半粗的次要文字作组名。
- **吸顶条**（记忆页各视图顶部的作用域、主线、筛选、小节页签与月份）：一个共用部件。随页面滚动贴住顶端（窄屏停在页首之下），画布色底，与内容列同宽并带内容列的内边距；贴住后下方多一道细线，内容可以据此收起（主线卡片收成胶囊）。与上下内容的间距就是所在列的间距，不另加减。
- **粘性提示条**：有未保存的改动时贴在主区底部，宽度与所在内容列相同；表面色、卡片圆角、浮起阴影，左侧写改动数（其中要重启的另起一行辅助标注），右侧放弃（描边）与保存（默认）。与保存有关、落不到字段上的失败以提示条叠在它上方。
- **设置项**：一行，名称在左，悬停显示解说，解说下以等宽字写键路径；解说要紧的少数几项名称后跟一个次要色的说明图标，其余不加；要重启才生效的项名称后跟一个小的重启图标，悬停说明。输入框在右，数值输入框宽为小卡片令牌，地址类占满剩余宽度并用等宽字。值与默认不同时输入框后出现幽灵按钮「默认 X」，点击恢复默认；超出取值范围时输入框下方以错误色写出范围。改动后未保存的输入框换成强调色描边。默认值与范围平时都不显示。
- **可开关的设置组**（如辅助模型）：一行摘要，左为开关，中为名称与一行现状，右为常在的「编辑」幽灵按钮；展开的设置在摘要下方，放在页面背景色的内衬里，不再套卡片。
- **日志条目列表**（日志页）：一张卡片内的有序列表，等宽字、小号字，放在卡片内的滚动区中（最大高度为日志滚动区令牌），卡片本身不随条目增高。跟随时有新条目而读者已向上翻看，滚动区底部居中浮出「N 条新日志」按钮（默认按钮，浮起阴影）。每条一行：时间（次要色、等宽数字）、级别代码（INF 为次要色，WRN 为警告色，ERR 为错误色，半粗）、消息（保留换行，自动折行）；WRN 与 ERR 的整行再以对应状态色的浅底标出，条目之间不加分隔线。窄屏时间与级别一行、消息另起一行。
- **磁贴**（设置页的绑定）：品牌标志的底块（标志令牌大小）在上、名称在下，可点：细描边，悬停时上浮、描边换成强调色；按标志令牌的倍数自动换行。标志右下角的圆形角标用状态色（成功为对勾，错误为叹号），外圈一道表面色描边把它与标志分开。新增用只有虚线描边的加号磁贴。
- **短码胶囊**（记忆页）：等宽小号字，抬起的表面色底、小圆角，次要文字色；整个胶囊是按钮，点一下复制短码，成功时短暂带上对勾并给出轻提示。
- **来源小字**（记忆页）：条目下一行辅助标注字号的次要文字，写日期（等宽数字）与原话。
- **画像条目**（记忆页的画像与主线约定）：圆角虚线框（细描边，半透明的次要文字色），框内上行是辅助标注字号的元信息（作用域小标签、日期、「原话」按钮，短码胶囊靠右且只在悬停或焦点进入时显示），下行是正文。有格式问题的条目换成警告色描边与浅底。
- **原话按钮与原话**（记忆页的画像条目与活动，共用一个部件）：浅强调色底、强调色字的圆形小按钮，带图标与向下的箭头，悬停与展开时换成强调色实底；展开的原话是左侧粗竖线的引文，有多条时各带日期。
- **活动条目**（记忆页的活动）：不加框，靠时间线竖轨上的圆点分开；上行是元信息（主线胶囊或虚线描边的「无主线」小胶囊、「原话」按钮，短码胶囊靠右且只在悬停或焦点进入时显示），下行是正文。
- **文件路径**（记忆页）：等宽小号的次要文字，过长时截断、悬停显示全文，旁边一个复制按钮，与可复制的地址相同。
- **主线胶囊**（记忆页）：完全圆角，强调色浅底配强调色文字，前面一个文件夹图标；不按主线分色。点了到主线视图；专题不是主线，只显示文字、不可点。
- **页面类型徽标**（记忆页）：中性色徽标，四种类型各一个图标（故障、决策、实体、工作），不用状态色；类型不是这四种时照原文显示。
- **正文排版**（细节页）：正文字号与正文行高，段落、列表、引用、代码块之间为小间距；小节内的标题从三级起，比小节标题小一级；列表标记为次要文字色；行内代码与代码块用抬起的表面色底与等宽字；引用左侧一道细线、文字为次要色；表格只有横线；链接为强调色，悬停加下划线。
- **出现记录的圆点**（画像候选）：每天一个小圆点，用热力图色阶；拒绝的那天为次要文字色，悬停显示日期。
- **客户端胶囊**（仪表盘的客户端卡片）：完全圆角，抬起的表面色底，左侧品牌标志的小底块、中间名称、右侧一个状态点（成功色为已绑定、危险色为绑定有问题、次要文字色为未绑定）；只展示，悬停显示状态与最近连接。胶囊之间为同一组控件的间隔、自动换行；下方一行图例写出现了的状态，状态不单靠颜色。超出上限时最后一个胶囊为强调色文字的「+N」链接。

目前已用的组件（在 `web/src/components/ui/`，由 shadcn/ui 生成后改写或按其结构编写）：按钮（默认、危险、描边、幽灵四种变体，常规与图标两种尺寸）、输入框、下拉框（外观同输入框的按钮，打开的选项列表样式同下拉菜单，当前项为强调色并带勾）、带显示切换的密码框、标签、卡片、徽标、提示条、轻提示、悬停提示、复制按钮、下拉菜单、确认对话框、模态对话框、侧边抽屉。图标取自 lucide-react；客户端（AI agent）的品牌标志取自 @lobehub/icons-static-svg，按单个 SVG 文件引入，只认得的几个用品牌标志，其余用通用的机器人图标；图标库里没有的（如 Oh My Pi）在 `web/src/assets/agents/` 下自绘。组件与页面一律用相对路径导入；`@/` 别名（指向 `web/src/`）保留给 shadcn/ui 命令行生成的代码。

## 5. 动效

### 两类动效（已定）

| 类别 | 用在哪 | 范围 |
| :--- | :--- | :--- |
| 界面动效 | 页面切换、卡片与列表项的出现、数值变化、对话框与浮层、操作进行中与完成 | 全站 |
| shader 背景 | 登录页、仪表盘顶部区域、空状态 | 只在不承载数据的区域 |

### 规则（已定）

- 动效服务于理解：说明东西从哪来、到哪去、状态变成了什么。不为动而动，不阻挡操作，不让用户等动画结束。
- 日志、设置表单、提示词编辑器的背后不放 shader 背景，文字区域的背景保持静止。
- **减少动态效果**：系统开启该设置时，界面动效退化为即时切换或简单的淡入淡出，shader 背景停在静止的一帧。
- shader 背景另有一个关闭开关，保存在浏览器本地，只影响当前浏览器。
- 页面不可见时暂停 shader 背景。

### 已实现的界面动效（已定）

- 悬停、焦点与颜色变化用快速时长与默认缓动，是组件的默认过渡。
- 可交互的卡片与按钮共用 `lift`：悬停上浮、按下缩小；减少动态效果时只变颜色与阴影，不移动。
- 进行中的命令把按钮图标换成转圈；减少动态效果时转圈不转。
- 热力图在悬停或聚焦一格时，下方一行就地换成那一天的内容，行高固定，卡片不跳动。
