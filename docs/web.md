# TacitMemory Web 界面

本文档说明 Web 界面做什么：有哪些页面、各页能做什么、保存与生效的规则。访问规则与管理 API 的约定见 `docs/reference/api.md`，视觉与动效规范见 `docs/ui-design.md`，配置项的含义见 `docs/reference/configuration.md`，代码组织见 `docs/architecture.md`。

本文描述目标形态。各节标题后的状态标明是否已实现：**已实现**、**部分**、**计划**。

## 1. 定位（已实现）

- Web 界面由常驻服务托管，地址为 `http://<主机>:<端口>/ui`；打开 `/` 会被带到 `/ui`。服务未运行时它不可用。
- 它只调用管理 API，不直接读写记忆仓库、派生索引或 `TACIT_HOME` 下的文件；它能做的每件事，规则都在核心中，与 `tacit` 命令共用。
- 它是配置、绑定、提示词文档、状态与日志的操作入口。记忆内容的写入仍由主会话经 MCP 工具完成，整理仍由 `tacit-consolidate` 开启，界面不提供替代入口。
- 界面的语言就是记忆语言，没有单独的切换；改 `language` 即同时改两者。
- 页面在手机浏览器上可用。

## 2. 访问与登录（已实现）

规则（哪些连接需要登录、访问密码的约束、会话）见 `docs/reference/api.md` 第 2 节，这里只写界面一侧的流程。

- 每个页面打开前先取会话状态。本机连接直接进入外壳，没有登录页；打开登录页时直接去仪表盘。
- 从其他设备打开时，任何地址都先到登录页（`/ui/login`），并记下原本要去的地址。输入访问密码登录后回到该地址，没有则去仪表盘。回跳只接受以 `/ui/` 开头的站内路径。
- 密码不对时，登录页显示服务返回的说明原文。同一地址连续输错达到限速条件后，服务返回的说明中写明还需等待的秒数；限速期间提交按钮禁用，直到用户改动密码输入框为止。
- 任何接口调用得到「会话缺失」（401）时，同样回到登录页并记下当前地址。修改访问密码时当前密码不对的 401 不触发跳转，它只显示在对应字段旁。
- 密码输入框可切换显示与隐藏；提交进行中禁用提交按钮。
- 导航中有「退出登录」，只在非本机连接时显示；退出后回到登录页。
- 登录后能做的事与本机完全相同。

## 3. 页面

外壳是左侧边栏：品牌、导航与当前连接的身份（本机，或已登录的其他设备及其退出登录）。导航固定为五项：仪表盘、设置、提示词、日志、记忆。窄屏下侧边栏改为抽屉，由页首的菜单按钮打开。

### 仪表盘（已实现）

宽屏下卡片排成网格：概览与记忆活动各占一整行，其下一行三张（辅助模型、备份、索引与整理），再一行两张（服务、客户端）。窄屏下卡片排成一列，概览、辅助模型与备份排在记忆活动之前，先看到要处理的事。

**概览**

- 一句状态：没有待处理的事时为「一切安好」，否则为「有 N 件事等你处理」；旁边是服务已运行的时长与上次整理在几天前。
- **待处理**：以下情况各列一条，每条链接到能解决它的地方；没有时显示「没有需要处理的事」。
  - 辅助模型未配置（几个模型合为一条，点名未配置的模型）→ 设置的「模型」一节；
  - 还没有任何绑定，或某个绑定检查出问题（每个绑定一条，写明问题）→ 设置的「绑定」一节；
  - 额外监听未能启动 → 设置的「通用」一节；
  - 上一次云端备份失败 → 本页的备份卡片。
- 模型冷却、待清理的候选与格式问题不列为待处理：前者会自己恢复，后两者留给整理。

**记忆活动**

- 近一年的日历热力图，每周一列、每天一格，颜色深浅表示当天的活动条数，整理过的日子另有标记。数据来自 `/api/activity`。
- 卡头给出窗口内的活动总数、活跃天数、最长连续天数与最活跃的主线。
- 悬停、点击或聚焦一格时，图下一行显示那一天的日期、活动条数、是否整理过与各主线的条数（未归属的排在最后）；方向键在日子间移动。
- 读不了的月文件与读不了的历史在卡片中注明，其余照常显示。

**辅助模型**

- 三个模型各一行：可用、冷却中（附倒计时）或未配置。
- 「探测」对已保存的配置逐个探测三个模型，结果（成功与耗时，或失败原因与耗时，未配置的跳过）显示在各模型下方；规则同 `tacit probe`。

**备份**

- 最新一份本地备份（种类、时间、大小）与本地备份的份数；云端备份的状态（未配置、还没有备份过，或上次尝试的时间与成败）。数据来自 `/api/backups`。
- 「立即备份」是下拉菜单：「本地备份」写到 `backups/`；「云端备份」上传到 `backup.webdav`，未配置时不可用。选中即执行，不再确认。
- 「恢复…」打开恢复对话框：
  - 从主机 `backups/` 下已有的备份（自动、手动、保险）与云端最新备份中选择，默认选中最新的本地备份；
  - 选中后显示预览（备份时间、版本、提交、文件数与将被替换的内容），云端备份先下载再预览；
  - 可选择一并恢复 `config.yaml` 与 `prompts/`；`bindings.json` 不受影响；
  - 确认后执行，期间对话框不能关闭；完成后显示保险备份的文件名、索引重建结果与服务的提示。
- 界面不提供备份到任意目录、从任意路径恢复或上传备份文件；这些仍用 `tacit backup --to` 与 `tacit restore --from`。

**索引与整理**

- 上次整理在几天前及其日期，以及待清理的候选、格式问题与未汇总的周的数量。
- 「重建索引」：确认后执行；确认对话框说明使用统计会清空、期间检索与写入排队。

**服务**

- 运行时长、版本、MCP 地址与 Web 地址（可复制）、额外监听（未设置、已监听或未能启动及原因）。

**客户端**

- 绑定与连接过的客户端合并为每个客户端一行：是否已绑定、绑定是否有问题、最近一次连接的日期。先列绑定，再列只连接过而没有绑定的客户端（最近连接的在前）。常见客户端显示其名称与图标，其余显示自报的名称与通用图标。
- 不显示客户端的能力、扩展与绑定的目录。还没有绑定时给出去添加绑定的链接。

**刷新与反馈**

- 状态报告每 30 秒刷新一次，记忆活动与备份列表在窗口重新获得焦点时刷新；命令执行后相关的数据随即刷新。
- 刷新失败时卡片保留上次的数据，页面顶部注明「无法连接到常驻服务」与所显示数据中最早的时间；从未取到数据时只显示这一句。
- 命令执行期间按钮显示进行中；成功以通知显示，失败以服务返回的说明显示在卡片或对话框中。状态报告中读不了的一栏，在对应卡片中注明并指向服务日志。

### 设置（部分）

目前只有「访问」一节已实现，其余各节仍为计划，页面上显示「尚未实现」。

**「访问」一节（已实现）**

- 显示当前是否已设访问密码。
- 设置与修改：输入新密码（可切换显示与隐藏）；非本机连接时另需输入当前密码。服务拒绝时，太短的说明显示在新密码旁，当前密码不对的说明显示在当前密码旁，其他失败显示在本节中；成功后以通知给出结果，说明其他设备上已有的登录已失效。
- 清除：只在本机连接且已设访问密码时出现；先经确认对话框，确认按钮写明「确认清除访问密码」。设了额外监听时清除按钮不可用：悬停或聚焦时说明原因，点击时（触屏只能如此）在本节中显示同一说明。
- 一句说明：额外监听地址（`server.host`）目前在 `config.yaml` 中填写，重启后生效。设置页完成后，这一项改在界面中编辑。

计划中的其余各节如下。

`config.yaml` 的每一项是一个控件，附解说、默认值与取值范围。分为通用、模型、检索与判断、整理、备份、绑定六节。

**保存与生效**

- 前五节各自保存，只提交本节。保存时由服务校验；不通过时不写文件，出错的字段各自显示原因。
- 保存成功后服务在进程内重新加载，新配置立即生效；重新加载期间的请求排队等待。保存或重新加载失败时，配置文件与运行中的服务都保持保存前的状态。
- 例外：
  - `server.port` 与 `server.host`：可以修改，保存后提示「重启 `tacit serve` 后生效」。
  - `memory.path`：只读显示。
  - 访问密码：单独设置与修改，即时生效，并使其他设备上已有的登录失效。`server.host` 填了 `127.0.0.1` 以外的地址而没有访问密码时，保存被拒绝。
- 每一项可以恢复为默认值。离开有未保存改动的页面时提醒。

**密钥**

- 密钥字段默认隐藏，点「显示」才向服务请求并显示该密钥的值。
- 每个密钥标明来源（环境变量或配置文件）。来自环境变量的只读；来自配置文件的可以改写。
- 访问密码无法显示，只能重设。

**探测**

- 模型一节可对已保存的配置执行探测，逐个模型显示结果；规则同 `tacit probe`。

**绑定**

- 列出现有绑定及其检查结果，内容与状态报告的绑定栏相同。
- 新增绑定：填客户端名称、上下文文件与 skill 目录。可先选一个**绑定预设**，它预填这三项，填好后仍可修改。路径是主机上的路径，由服务检查；被拒绝时显示的原因与 `tacit connect` 相同。
- 绑定成功后显示 MCP 端点信息（地址、传输方式、建议的服务名），可复制。界面不替用户修改客户端的 MCP 配置。
- 解除绑定：确认后执行，规则同 `tacit disconnect`。
- 新增与解除是立即执行的操作，没有保存按钮。

第一版的绑定预设：

| 客户端名称 | 上下文文件 | skill 目录 |
| :--- | :--- | :--- |
| `claude` | `~/.claude/CLAUDE.md` | `~/.claude/skills` |
| `omp` | `~/.omp/agent/AGENTS.md` | `~/.omp/agent/skills` |
| `agy` | `~/.gemini/config/AGENTS.md` | `~/.gemini/config/skills` |

预设只是界面中的预填数据，服务不区分绑定是否来自预设。

### 提示词（计划）

- 四份提示词文档各一个编辑器，显示当前内容、字符数与上限。
- `instructions.md` 与 `resident.md` 不存在时，显示内置默认文本并标明「正在使用内置默认」；点「开始自定义」以该文本为起点创建文件。
- 保存时由服务按 `docs/reference/configuration.md`「提示词文档」的规则校验，不通过则拒绝保存并指出原因。手动改文件时的行为不变（出错的文件沿用上一版并提示）。
- 「恢复默认」删除 `instructions.md` 或 `resident.md`，回到内置文本。
- 保存后何时生效与手动修改相同。

### 日志（计划）

- 选择日期查看 `logs/` 下当天的日志，按级别与关键字筛选。
- 「实时跟随」打开后，新写入的日志自动出现。
- 只读：不提供清空与删除。

### 记忆（计划）

范围在实现该页时确定。

## 4. 不做的事

| 不做 | 原因或归属 |
| :--- | :--- |
| 初始化向导 | 初始化由 `tacit init` 完成，之后在设置页配置；仪表盘的待完成提示承担引导 |
| 账号与权限分级 | 使用者只有一人 |
| 界面语言的单独切换 | 只有记忆语言一个语言概念 |
| 一键整理 | 整理由主会话完成，服务不调用生成模型 |
| 需要另存历史数据的图表 | 服务不保存历史指标 |
| 上传备份文件、指定任意主机路径 | 仍由命令行提供 |
| 替用户修改客户端的 MCP 配置 | 绑定不代写 MCP 配置 |
