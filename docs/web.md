# TacitMemory Web 界面

本文档说明 Web 界面做什么：有哪些页面、各页能做什么、保存与生效的规则。访问规则与管理 API 的约定见 `docs/reference/api.md`，视觉与动效规范见 `docs/ui-design.md`，配置项的含义见 `docs/reference/configuration.md`，代码组织见 `docs/architecture.md`。

本文描述目标形态。各节标题后的状态标明是否已实现：**已实现**、**部分**、**计划**。

## 1. 定位（已实现）

- Web 界面由常驻服务托管，地址为 `http://<主机>:<端口>/ui`；打开 `/` 会被带到 `/ui`。服务未运行时它不可用。
- 它只调用管理 API，不直接读写记忆仓库、派生索引或 `TACIT_HOME` 下的文件；它能做的每件事，规则都在核心中，与 `tacit` 命令共用。
- 它是配置、绑定、提示词文档、状态与日志的操作入口。记忆内容的写入仍由主会话经 MCP 工具完成，整理仍由 `tacit-consolidate` 开启，界面不提供替代入口。
- 界面的语言就是记忆语言，没有单独的切换；改 `language` 即同时改两者。
- 页面在手机浏览器上可用。

## 2. 访问与登录（已实现）

规则（哪些连接需要登录、访问密码的约束、会话）见 `docs/reference/api.md` 第 2 节，这里只写界面一侧的流程。

- 每个页面打开前先取会话状态。本机连接直接进入外壳，没有登录页；打开登录页时直接去仪表盘。
- 从其他设备打开时，任何地址都先到登录页（`/ui/login`），并记下原本要去的地址。输入访问密码登录后回到该地址，没有则去仪表盘。回跳只接受以 `/ui/` 开头的站内路径。
- 密码不对时，登录页显示服务返回的说明原文。同一地址连续输错达到限速条件后，服务返回的说明中写明还需等待的秒数；限速期间提交按钮禁用，直到用户改动密码输入框为止。
- 任何接口调用得到「会话缺失」（401）时，同样回到登录页并记下当前地址。修改访问密码时当前密码不对的 401 不触发跳转，它只显示在对应字段旁。
- 密码输入框可切换显示与隐藏；提交进行中禁用提交按钮。
- 导航中有「退出登录」，只在非本机连接时显示；退出后回到登录页。
- 登录后能做的事与本机完全相同。

## 3. 页面

外壳是左侧边栏：品牌、导航与当前连接的身份（本机，或已登录的其他设备及其退出登录）。导航固定为五项：仪表盘、设置、提示词、日志、记忆。窄屏下侧边栏改为抽屉，由页首的菜单按钮打开。

### 仪表盘（已实现）

宽屏下卡片排成网格：概览与记忆活动各占一整行，其下一行四张小卡片（辅助模型、备份、索引与整理、日志），最后一行是服务（约三分之一宽）与客户端。窄屏下卡片排成一列，概览、辅助模型与备份排在记忆活动之前，先看到要处理的事。

卡片的命令放在卡头标题的右侧，是只有图标的按钮，悬停或聚焦时以提示气泡显示名称；卡片底部不放按钮，也不加分隔线，同一行里内容少的卡片在下方留白。

**概览**

- 一句状态：没有待处理的事时为「一切安好」，否则为「有 N 件事等你处理」；旁边是服务已运行的时长与上次整理在几天前。
- **待处理**：以下情况各列一条，每条链接到能解决它的地方；没有时显示「没有需要处理的事」。
  - 辅助模型未配置（几个模型合为一条，点名未配置的模型）→ 设置的「模型」一节；
  - 还没有任何绑定，或某个绑定检查出问题（每个绑定一条，写明问题）→ 设置的「绑定」一节；
  - 某份提示词文档的文件有误、服务正在沿用上一版（每份一条，写明原因）→ 提示词页的这份文档；
  - 额外监听未能启动 → 设置的「远程访问」一节；
  - 上一次云端备份失败 → 本页的备份卡片。
- 模型冷却、待清理的候选与格式问题不列为待处理：前者会自己恢复，后两者留给整理。

**记忆活动**

- 近一年的日历热力图，每周一列、每天一格，颜色深浅表示当天的活动条数，整理过的日子另有标记。数据来自 `/api/activity`。
- 卡头给出窗口内的活动总数、活跃天数、最长连续天数与最活跃的主线。
- 悬停、点击或聚焦一格时，图下一行显示那一天的日期、活动条数、是否整理过与各主线的条数（未归属的排在最后）；方向键在日子间移动。
- 读不了的月文件与读不了的历史在卡片中注明，其余照常显示。

**辅助模型**

- 三个模型各一行：可用、冷却中（附倒计时）或未配置。
- 卡头的「探测」逐个探测三个模型，结果（成功与耗时，或失败原因与耗时，未配置的跳过）显示在各模型下方；规则同 `tacit probe`。

**备份**

- 最新一份本地备份的时间、种类（自动备份、手动备份或恢复前的保险备份）与大小，以及本地备份的份数；云端备份的状态（未配置并附去设置的链接、已配置但尚未备份，或上次尝试的时间与成败）。数据来自 `/api/backups`。
- 卡头的「立即备份」（主要按钮，带下拉箭头）是下拉菜单：「本地备份」写到 `backups/`；「云端备份」上传到 `backup.webdav`，未配置时不可用。选中即执行，不再确认。
- 卡头的「恢复…」打开恢复对话框：
  - 从主机 `backups/` 下已有的备份（自动、手动、保险）与云端最新备份中选择，默认选中最新的本地备份；
  - 选中后显示预览（备份时间、版本、提交、文件数与将被替换的内容），云端备份先下载再预览；
  - 可选择一并恢复 `config.yaml` 与 `prompts/`；`bindings.json` 不受影响；
  - 确认后执行，期间对话框不能关闭；完成后显示保险备份的文件名、索引重建结果与服务的提示。一并恢复的 `config.yaml` 立即生效，需重启的项列在提示中，设置页随之标出「待重启」。
- 界面不提供备份到任意目录、从任意路径恢复或上传备份文件；这些仍用 `tacit backup --to` 与 `tacit restore --from`。

**索引与整理**

- 上次整理在哪天（今天、昨天或几天前，两天以上附日期）。
- 等下次整理处理的事，各一行、只列有的：候选、格式有问题的文件、还没有汇总的周；都没有时显示「一切正常」。
- 卡头的「重建索引」：确认后执行；确认对话框说明使用统计会清空、期间检索与写入排队。

**服务**

- 卡片标题旁是服务的版本；运行时长见概览。
- MCP 地址与 Web 地址（可复制）、额外监听（未设置、已监听、未能启动及原因，或服务未运行时配置的地址）。

**客户端**

- 绑定与连接过的客户端合并为每个客户端一个胶囊：图标、名称，以及一个表示绑定状态的圆点（已绑定、绑定有问题、未绑定只连接过）。先列绑定，再列只连接过而没有绑定的客户端（最近连接的在前）。常见客户端显示其名称与图标，其余显示自报的名称与通用图标。
- 悬停在胶囊上显示绑定状态（有问题时为问题所在）与最近一次连接的日期，读屏时随名称读出。胶囊下方一行图例，只列出现了的状态。
- 至多显示 12 个；更多时最后一个胶囊写「+N」，点它去设置的「绑定」一节。有客户端时，卡头的「管理绑定」去同一处。
- 不显示客户端的能力、扩展与绑定的目录。还没有绑定时说明这一点，并给出去添加绑定的按钮。读不了绑定时胶囊不带圆点、没有图例，并说明读不了。

**日志**

- 今天的服务日志中有几条警告、几条错误，以警告色、错误色显示；都没有时显示「没有警告与错误」；今天的文件读不了时注明读不了。
- 卡头的「查看日志」打开日志页：有警告或错误时只显示这两级，否则显示今天的全部日志。日志的警告与错误不进入概览的待处理。

**刷新与反馈**

- 状态报告每 30 秒刷新一次，记忆活动与备份列表在窗口重新获得焦点时刷新；命令执行后相关的数据随即刷新。
- 刷新失败时卡片保留上次的数据，页面顶部注明「无法连接到常驻服务」与所显示数据中最早的时间；从未取到数据时只显示这一句。
- 命令执行期间按钮显示进行中；成功以通知显示，失败以服务返回的说明显示在卡片或对话框中。状态报告中读不了的一栏，在对应卡片中注明并指向服务日志。

### 设置（已实现）

设置页取代手写 `config.yaml`：`config.yaml` 的每一项是一个控件，附解说。页面是从上往下读的一列，各节依次为模型、绑定、检索与判断、整理、备份、远程访问、高级。

**页面结构（已实现）**

- 单列，限宽居中；每节是一张卡片：卡头是该节的图标、标题与一句用途说明，下面是一组或几组设置。组不另加框，只有小标题与需要时的一句说明；项与项之间、组与组之间只靠留白区分，不加线。
- 侧边栏「设置」下列出各节，可折叠，浏览器记住是否折叠；点击滚到对应一节，滚动时标出正在读的一节，有出错字段的节在名称后显示出错数。
- 每一项一行：名称在左，输入框在右，窄屏叠成上下。悬停名称时显示解说与它在 `config.yaml` 中的键路径。解说说出名称与输入框之外要紧的事的几项（端口、额外监听地址、最低重排分、整理时限、自动备份份数），名称后有一个小的说明图标；其余不加，免得满页图标。
- 默认值与取值范围平时不显示：值与默认不同时，输入框后出现「默认 X」按钮，点击恢复默认；输入的数超出取值范围时，输入框下方写出范围。改动后尚未保存的输入框为强调色描边。
- 立即执行、不经保存的部分（绑定、访问密码）在标题旁标「立即生效」。

**保存与生效（已实现）**

- 全页统一保存：任何一项改动后，页面底部浮出提示条，写明改动数（其中要重启才生效的另写一行），带「放弃」与「保存」。放弃先经确认，各项回到保存过的值。
- 保存时提交整份配置。等于默认的项不写入文件，此后随默认值；一对阈值只要有一个不同于默认就两个都写。输入的不是数字（或需要整数而不是）时不发请求，原因显示在字段旁。
- 服务校验整份配置，一次报告全部问题：落在本页字段上的显示在字段旁，页面滚到第一个出错的字段并聚焦；本页没有的键汇总在提示条上方。不通过时文件不变。
- 通过后服务写文件并在进程内重新加载，新配置立即生效，以通知给出结果；重新加载期间的请求排队等待。新配置打不开时文件写回原样，服务按原配置继续运行，失败原因显示在提示条上方。
- 打开页面之后 `config.yaml` 又被修改过时，保存被拒绝，提示条上方显示原因与「重新载入」；重新载入会丢弃未保存的改动，先经确认。
- `config.yaml` 无法加载时（被手动改坏，或从备份恢复回来就有错误），页面只显示出错的键路径与原因，说明服务仍按上次加载的配置运行，并给出「重新读取」；在文件中改好后重新读取即可回到设置页。
- `config.yaml` 被手动修改、服务尚未重新加载时，即时生效的项中文件与运行中的值不同者在页首以警告列出，在本页保存任何改动或重启服务后生效。
- 离开有未保存改动的页面时提醒：应用内跳转先经确认对话框，关闭或刷新标签页时由浏览器询问。
- 例外：
  - `server.port`、`server.host` 与 `limits.page.minAliases`：可以修改，名称旁有一个重启的小图标，悬停说明保存后要重启才生效。保存后若改动了其中的项，以对话框列出「运行中的值 → 新值」，说明其余改动已生效、这几项重启 `tacit serve` 后生效，只有「知道了」；不弹对话框时以通知给出结果。在重启之前，这几项旁标「待重启」并写出运行中的值；标记由文件与运行中的值之差得出，刷新页面或换设备打开后仍在。
  - `memory.path` 与 `language`：在「高级」一节末尾以纯文本显示，整组注明只在 `config.yaml` 中修改、重启后生效；提交的值与文件不同时保存被拒绝。
  - `server.host` 填了 `127.0.0.1` 以外的地址而没有访问密码时，保存被拒绝；未设访问密码时这一项不可填，下方说明要先设访问密码。
  - 访问密码：单独设置与修改，即时生效，并使其他设备上已有的登录失效，不计入改动数。

**「模型」一节（已实现）**

- 三个辅助模型上下排列，各占一行：启用开关、名称，开着时一行写模型 ID · 协议 · URL，关着时写「未启用」与它的用途。有未保存的改动时名称旁有一个强调色圆点。
- 每行右侧的「编辑」常在，与开关无关；点开后在该行下方展开协议（通用协议或 Cloudflare）、URL、模型 ID 与 API 密钥，一次展开一个。协议下方一行写所选协议对这个模型意味着什么（按哪种格式请求、URL 要填什么）；URL 为空时以示例地址作占位。保存时有问题的模型自动展开。
- 关掉开关的模型保存后从 `config.yaml` 中删除；页面上已填的内容保留，关着时也可以先填，再打开即恢复；关着时不计入改动数，也不校验。启用时 URL 与模型 ID 必填。
- 底部的「探测」见下文。

**「绑定」一节（已实现）**

- 每个已绑定的客户端是一块磁贴：品牌标志与名称，认得的客户端用它的品牌名（如 Claude Code），其余用绑定名与通用图标；标志右下角的角标表示是否正常（绿色对勾或红色叹号）。内容与状态报告的绑定栏相同。
- 点磁贴打开详情对话框：问题的说明、上下文文件与 skill 目录的完整路径、共用路径的其他绑定，以及在客户端中注册 MCP 服务所需的地址、传输方式与建议的服务名，各自可复制。底部可解除绑定：在对话框内再确认一次，规则同 `tacit disconnect`。
- 最后一块「新增」打开新增绑定的对话框：先选客户端，尚未绑定的**绑定预设**以品牌标志列出，另有「其他」手填；再确认客户端名称、上下文文件与 skill 目录（预设已预填，可修改），可退回重选。路径是主机上的路径，由服务检查；被拒绝时显示的原因与 `tacit connect` 相同。绑定成功后显示 MCP 服务的注册信息，并说明 MCP 只接受本机连接；做了什么的摘要折叠在其下。界面不替用户修改客户端的 MCP 配置。
- 仪表盘待处理项中指向设置的链接跳到对应的一节。

第一版的绑定预设：

| 客户端名称 | 上下文文件 | skill 目录 |
| :--- | :--- | :--- |
| `claude` | `~/.claude/CLAUDE.md` | `~/.claude/skills` |
| `omp` | `~/.omp/agent/AGENTS.md` | `~/.omp/agent/skills` |
| `agy` | `~/.gemini/config/AGENTS.md` | `~/.gemini/config/skills` |

预设只是界面中的预填数据，服务不区分绑定是否来自预设。

**「检索与判断」一节（已实现）**

- 检索：`retrieval.candidates`、`retrieval.topK`、`retrieval.minRerankScore`。
- 判断阈值：四种判断各一行，「确定 ≥」与「否定 ≤」两个输入框并排，可整行恢复默认；四种的默认值相同时写在表头。其上一句说明阈值的含义，以及默认值是用某一个决策模型实测标定的，换模型后需自行核对。

**「整理」一节（已实现）**

- `consolidation` 的六项，一项一行。

**「备份」一节（已实现）**

- 本地：`backup.keep`。
- 云端（WebDAV）：`backup.webdav.url`、`backup.webdav.username` 与密码。目录与用户名都清空即不使用云端备份。

**「远程访问」一节（已实现）**

- 先是访问密码：显示当前是否已设。设置与修改：输入新密码（可切换显示与隐藏）；非本机连接时另需输入当前密码。服务拒绝时，太短的说明显示在新密码旁，当前密码不对的说明显示在当前密码旁，其他失败显示在本节中；成功后以通知给出结果，说明其他设备上已有的登录已失效。
- 清除访问密码：只在本机连接且已设访问密码时出现；先经确认对话框，确认按钮写明「确认清除访问密码」。设了额外监听时清除按钮不可用：悬停或聚焦时说明原因，点击时（触屏只能如此）在本节中显示同一说明。
- 然后是 `server.host`（不填则只监听本机），随全页保存。

**「高级」一节（已实现）**

- `server.port`、`limits.brief`、`limits.page.minAliases`。
- 末尾是只读的 `memory.path` 与 `language`。

**密钥（已实现）**

- 密钥字段默认以掩码显示，点「显示」才向服务请求并显示该密钥当前生效的值（环境变量优先）。
- 来自环境变量的密钥只读，只显示一行「来自环境变量」与变量名，悬停说明要改这个环境变量并重启。来自 `config.yaml` 的注明以明文写在文件中、也可改用环境变量；未设置的注明填写后以明文写入文件。来自 `config.yaml` 或未设置的可以「改写」：输入新的值；来自 `config.yaml` 的还可以「清除」，保存后从文件中删除。改写与清除各计一项改动，可以撤销；改写为空时不发请求。
- 不碰密钥时保存其他项，密钥保持文件中原有的值。
- 访问密码无法显示，只能重设。

**探测（已实现）**

- 模型一节可对已保存的配置执行探测，结果显示在各模型的摘要行下；规则同 `tacit probe`。页面有未保存的改动时探测按钮不可用，并说明要先保存。

### 提示词（已实现）

**查看（已实现）**

- 四份提示词文档（核心规则 `instructions.md`、值得记标准 `rules.md`、常驻区块 `resident.md`、写法约定 `skill.md`）各有自己的地址 `/ui/prompts/<文档名>`；`/ui/prompts` 与未知的文档名转到核心规则。
- 侧边栏「提示词」下列出四份文档，标出正在看的一份；用户有文件的文档名后有一个铅笔图标（已自定义）。
- 一次显示一份文档，是一张卡片：卡头是图标、名称、文件名、「内置默认」或「已自定义」的徽标与一个信息按钮；悬停或聚焦徽标时说明现在用的是文件还是内置文本。点信息按钮打开一个浮层，说明这份文档进入哪个环节、管什么、何时生效，常驻区块另列出允许的六个节名，最后同样说明现在用的是哪份文本。卡头下是文档的文本，在 Markdown 编辑器里：等宽字体、带行号，标题、标记符号、注释、行内代码与链接各有颜色，深色主题另有一套。
- 文件不存在时显示内置默认文本（写法约定的内置默认为空），文件存在时显示文件的原文。
- 从备份恢复并一并恢复配置后，页面重新读取四份文档。

**编辑（已实现）**

- 内置默认只读，点「开始自定义」以内置文本为起点编辑，此时不改动也可保存，即把内置文本写成文件；写法约定的内置默认为空，直接可编辑。每份文档单独保存，有未保存的改动时可「放弃」（需确认）。
- 保存时由服务按 `docs/reference/configuration.md`「提示词文档」的规则校验，核心规则与值得记标准的合计以候选文本加另一份运行中的文档计算；不通过时文件不变，页面列出全部错误，文字与启动、重新加载时相同。通过后写文件并立即生效：服务端说明在下一个会话采用新文本，记忆 skill 重新生成，常驻区块重新渲染。成功后提示「已保存，下一个会话生效」；常驻区块有绑定渲染失败时，卡片内列出原因。
- 打开页面后文件在别处被改过（或被创建、删除），保存不覆盖，提示后可「重新载入」（需确认，丢弃未保存的改动）。
- 已自定义的文档有「恢复默认」（需确认）：删除文件，回到内置文本，同样立即生效；内置文本放不下时（如很长的核心规则旁的内置值得记标准）拒绝并保留文件。内置默认时不显示此按钮。
- 有未保存的改动时，切换到另一份文档、离开页面与关闭或刷新标签页前都会询问，做法同设置页。

**额度（已实现）**

- 文本下方一行显示长度：常驻区块与写法约定为字数与上限；核心规则与值得记标准没有自己的上限，显示服务端说明固定部分的合计「X / 3000」，以及最近活动还能用的字符数（总长 4000 减去固定部分）；值得记标准另显示两节各自的条目数「n / 10」。超过上限的部分以危险色显示，数字本身也写明超出；最近活动没有空间时照实写出还差多少。
- 长度按下发后的文本计：核心规则去掉独占一行的注释，值得记标准按排版后的长度，且都以另一份运行中的文档合计。
- 编辑框随内容增高，不出现内部滚动条，页面整体滚动。编辑器支持撤销与重做；在列表项末尾回车会续上列表标记。编辑器的代码只在打开提示词页时加载。
- 输入停顿约 0.4 秒后由服务校验当前文本，返回长度与全部错误；有错误时文本下方当场列出，与保存时的拒绝说法相同。未改动的文本直接使用读取时附带的长度，不再请求。校验请求失败时编辑照常，只是暂不显示长度。

**文件有误（已实现）**

- 服务运行中手动把文件改坏时，服务沿用这份文档的上一版并记住原因（核心规则与值得记标准合计超限时两份都记下）。提示词页在这份文档的卡片顶部显示「文件有误，服务正在使用上一版」与原因，编辑框里仍是文件现在的内容；侧边栏的文档名后有警告标记；仪表盘的待处理与 `tacit status` 也列出它。
- 改正文件、在页面上保存或恢复默认后，服务改用新内容，三处随之恢复正常。

### 日志（已实现）

**查看（已实现）**

- 侧边栏的「日志」打开 `/ui/logs`，显示今天的服务日志；`/ui/logs/<日期>` 显示指定的一天（`yyyy-MM-dd`），`/ui/logs/<今天>` 转到 `/ui/logs`。卡头写出日期与星期（今天前加「今天」），右侧「选择日期」列出今天与有日志文件的日期，最新在前。
- 日志从旧到新排列，新的在底部，放在卡片内的滚动区中：卡片高度随窗口而定，不随条目撑开，条目多时在区内滚动。每条显示时间（时:分:秒.毫秒，按文件中写下的时间，与浏览器所在时区无关）、级别（INF、WRN、ERR，悬停显示级别名）与消息；WRN 与 ERR 的整行以警告色、错误色的浅底标出。一条日志之后的续行（配置错误列出的多条原因、异常堆栈）与它显示为一条，保留换行。宽屏一条一行，窄屏时间与级别一行、消息另起一行；长消息换行，不出现横向滚动。
- 今天还没有日志时显示空状态说明；地址中的日期没有日志（超出保留的 14 天，或那天服务没有运行）时说明这一点，并给出回到今天的按钮。
- 带配置的恢复完成后重新读取。

**筛选（已实现）**

- 卡头下方一行筛选：INF、WRN、ERR 三个级别开关，各带当天该级别的条数，默认全开，最后一个开着的不能关；关键字输入框，不区分大小写的子串匹配（按字面，不是正则表达式），续行中的命中也算，命中处高亮；右侧写「共 N 条」，有筛选时为「显示 X / 共 Y 条」。
- 筛选条件在地址中：`level` 为逗号分隔的级别（`information`、`warning`、`error`，缺省为全部，未知值忽略），`q` 为关键字。改动筛选替换当前地址、不新增历史记录；切换日期时保留筛选；刷新后仍在。
- 筛选后没有结果时说明这一点，并给出「清除筛选」。

**实时跟随（已实现）**

- 查看今天时卡头有「实时跟随」开关，默认打开；查看过去的日子时没有这个开关，那天的文件不再变化。
- 打开时滚动区停在最新一条，每 2 秒向服务要一次已有条数之后的新日志，追加在末尾并经过当前的筛选；标签页不在前台时不发请求，回到前台立即补一次。
- 滚动区位于底部时，新日志到来就滚到底；向上翻看后不再自动滚动，滚动区底部浮出「N 条新日志」（只计通过当前筛选的），点它平滑回到底部并恢复自动滚动；系统设了减少动态效果时直接跳到底部。
- 过了零点，服务的「今天」变为新的一天后，页面在补完前一天剩下的日志后转到新的一天。
- 服务暂时连不上（如重启）时，已有的日志留在页面上，上方一行说明，之后照常重试，恢复后说明消失、继续跟随。

只读：不提供清空、删除与下载。

### 记忆（部分实现）

只读：浏览记忆与执行检索追踪，都不改动任何文件，也不计入使用统计（主线简报的排序不因此变化）。记忆的写入仍由主会话经 MCP 工具完成，候选的晋升在整理中完成。

侧边栏「记忆」之下列出五个视图，样式与提示词页的文档清单相同：画像、主线、细节页、活动、检索。`/ui/memory` 打开画像。活动尚未实现，显示占位。

**画像**

- 全局画像一张卡片，红线、协作规则、偏好、档案四节依次列出，各写条数，没有条目的一节写「暂无条目」；每个领域、每条主线各一张卡片，按标签与名称排序，领域在标题下写触发描述（缺少时以警告色写明）。红线不用错误色，以图标区分。
- 每条画像条目显示正文与续行，其下以浅色小字写来源（日期与原话），右侧是短码胶囊，点一下复制短码，可直接交给 Agent 替换或删除这一条。
- 画像候选一张卡片在最后：每个候选写正文、归属与作用域，出现记录按日期画成一排圆点（同一天只画一个）并写出现天数。拒绝列表默认折叠，展开后逐条写出现记录的日期与原话，拒绝的那天标「拒绝」。
- 文件有格式问题时，能读的照常显示：问题落在某一条上时，这一条以警告色浅底标出并在其下写明问题；落不到条目上的（如无法识别的小节）列在卡片顶部的提示条里。问题文字与整理报告相同。`persona.md` 与 `candidates.md` 不存在时视为空。
- 全局画像与画像候选两张卡片的标题下写出对应文件的完整路径，旁边有复制按钮。
- 仪表盘「索引与整理」卡片中「N 条候选等下次整理」一行链接到这里的画像候选。

**主线**

- 宽屏下左侧是主线清单、右侧是选中主线的简报（`/ui/memory/workstreams/<名>`），选中的一条高亮，清单随页面滚动吸顶；没有选中时右侧提示从左侧选一条。窄屏下清单与简报是两层地址，简报顶部有返回清单的链接。
- 清单：已成立的主线按 `workstreams.md` 中的顺序在前，细节页或活动用到、但没有成立的主线名按名称在后，样式较淡。每条写名称、背景说明与近期摘要（各至多两行）、近 26 周的迷你活动条（每周一格，取自仪表盘热力图的同一份数据，色阶相同，按一周的条数分档）、页数与最近一条活动的日期。
- 简报与 Agent 调用 `recall` 时的主线简报取数与排序相同，但不截断、不计入使用统计。头部写名称、背景说明与近期摘要；未成立的主线没有这两行，改为提示整理时可以提议成立。其下依次为：主线约定（与画像视图的条目相同，带短码胶囊与来源小字）；未决事项（工作页「遗留」一节的各行，警告色浅底，页面标识链接到所在的细节页）；页目录（按决策、故障、工作、实体分组，没有有效类型的在最后，每页写标题、别名、最近修改日期与召回次数，整行点开这一页；被推翻的决定单独一行，以删除线列出）；最近活动（日期、正文与短码胶囊）与最近一次周汇总，卡头有「在活动中查看全部」，打开按这条主线筛选的活动视图。

**细节页**

- 清单：全部细节页按主线分组，每条主线一张卡片，按名称排序，专题一组排在最后。每行写标题、浅色的别名、页面类型徽标、最近修改日期与召回次数，整行点开这一页。顶部按关键字（匹配标题与别名，不分大小写，输入即过滤）、主线与页面类型筛选；筛选条件写在地址中（`q`、`workstream`、`type`），可收藏。
- 单页（`/ui/memory/pages/<主线>/<slug>`）：页首是位置（细节页 › 主线 › 标题）；页头卡片写标题、页面类型、别名、首末日期、主线胶囊（点了到主线视图；专题不可点）、召回次数、`related` 中的页面（存在的可点，不存在的写「页面不存在」）与文件路径。页面有格式问题时页头卡片中列出，文字与整理报告相同；非 UTF-8 或页头读不出时，能读的照常显示。
- 每个小节一张卡片：小节名、短码胶囊、修改日期与召回次数，其下是排版后的正文。正文中的 HTML 一律按文字显示，链接只跟随 http、https、mailto 与站内地址；来源注释显示为浅色小字的日期与原话，其他注释不显示。宽屏下右侧是小节目录，点了跳到对应小节。
- 检索视图中页面结果的页面标识与小节名链接到这里，小节名跳到对应小节。

**检索**（检索追踪）

- 检索条件与 `recall` 的检索相同：查询、主线（留空为全部主线）、范围（页面与活动、只看页面、只看活动）与起止日期。条件有误时，说明显示在对应的输入框下。
- 结果在左：Agent 收到的结果，与 `recall` 的分组与顺序相同；页面显示页面标识、标题与显示的小节，活动与汇总显示日期、短码与正文。卡片底部写明全文检索方式（短语匹配、单字子串匹配、没有可检索的文本）与两个模型的耗时。
- 检索单元在右，按去向分为四段：显示、超出 topK、低于阈值、融合后在候选数之外。每段写明单元数（显示一段另写结果数）与占全部单元的比例条；每个单元一行，依次为名称（页面标识与小节名，页面的标题与别名称「线索」；活动的短码与日期；汇总的周期）、全文名次、向量名次与 reranker 分，没有的为「—」。去向用图标加文字表示，不只靠颜色。结果在前 topK 内、但页面已读不出的单元，归入超出 topK 一段。
- 与 `recall` 共用辅助模型的冷却状态，即还原 Agent 当下实际得到的结果。
- 临时替换检索参数：最低 rerank 分数、topK 与候选数折叠在检索条件之下，只对这次检索生效，不改配置；留空即用配置中的值（输入框的占位文字）。与配置不同的值旁标「与配置不同」，下方写明配置中的值。
- 结果可切换为「原文」：Agent 从 `recall` 收到的文本，逐字相同。
- 配置了的辅助模型没有作答时（冷却中或调用失败），结果上方提示检索如何降级：嵌入模型未作答时结果只来自全文检索；reranker 未作答时保留融合后的顺序、不按最低分数过滤。
- 低于阈值与融合后在候选数之外两段先列前 5 个单元，其余点「展开」再列出。
- 检索条件写在地址中（`q`、`workstream`、`from`、`to`、`kind`、`min`、`topK`、`candidates`），打开带查询的地址即执行检索，可收藏或分享；条件不变时再点「检索」重新执行。

## 4. 不做的事

| 不做 | 原因或归属 |
| :--- | :--- |
| 初始化向导 | 初始化由 `tacit init` 完成，之后在设置页配置；仪表盘的待完成提示承担引导 |
| 账号与权限分级 | 使用者只有一人 |
| 界面语言的单独切换 | 只有记忆语言一个语言概念 |
| 一键整理 | 整理由主会话完成，服务不调用生成模型 |
| 需要另存历史数据的图表 | 服务不保存历史指标 |
| 上传备份文件、指定任意主机路径 | 仍由命令行提供 |
| 替用户修改客户端的 MCP 配置 | 绑定不代写 MCP 配置 |
